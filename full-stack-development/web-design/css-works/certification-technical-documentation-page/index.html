Introduction to Flexbox

Flexbox is a one-dimensional layout model that distributes space among items in a container and aligns them along a main axis and a cross axis.

It is ideal for navigation bars, card rows, centering content, and any layout where items need to share available space predictably.

display: flex;
  • Main axis — the primary direction items are laid out.
Flex Container

A flex container is any element with display: flex or display: inline-flex. Its direct children become flex items.

The container controls direction, wrapping, alignment, and spacing between items through its properties.

display: flex;
  • Children of a flex container are automatically flex items.
Flex Direction

flex-direction sets the main axis: row, column, row-reverse, or column-reverse.

Changing the direction flips both the main axis and the cross axis, which affects how alignment properties behave.

flex-direction: column;
  • row is the default and lays items horizontally.
Justify Content

justify-content aligns items along the main axis. Common values are flex-start, center, flex-end, space-between, space-around, and space-evenly.

It only works when there is free space left along the main axis after items have been sized.

justify-content: space-between;
  • space-between pushes the first and last items to the edges.
Align Items

align-items aligns items along the cross axis. Values include stretch, flex-start, center, flex-end, and baseline.

To center a single item on the cross axis without affecting the others, use align-self on that item instead.

align-items: center;
  • stretch is the default and fills the cross axis.
