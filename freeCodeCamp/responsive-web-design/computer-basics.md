# Basics of html and css development

An example folder structure for an HTML and CSS project:
```
.
├── assets
│   ├── images
│   │   ├── logo.png
│   │   ├── banner.jpg
│   │   └── icons.svg
│   ├── fonts
│   │   ├── custom-font.woff
│   │   └── custom-font.woff2
├── css
│   ├── main.css
│   ├── about.css
│   └── contact.css
├── index.html
├── about.html
├── contact.html
└── README.md
```

## File types
| type | description |
| --- | --- |
| .html | HTML files (contain the structure and content of the web application) |
| .css | CSS files (define the styles) |
| .js | JavaScript files (add more advanced functionality and interactivity) | 

| image type | - | description |
| --- | --- | --- |
| JPEG | Joint Photographic Experts Group | It's *great for photographs and images*. However, the compression is lossy, which means that some image quality is lost to reduce the file size. |
| PNG | Portable Network Graphics | This results in larger files. PNG supports transparency and it's *great for images with sharp edges*, like logos and icons. |
| GIF | Graphics Interchange Format | *Supports both animation and transparency* but has a limited color palette. |
| SVG | Scalable Vector Graphics | It's a *vector image format*. These images can be scaled as much as needed without losing quality. |

| audio type | description |
| --- | -- |
| MP3  | is an audio format known for its efficient compression. It's a lossy format, so some audio data is lost during the compression to make these files smaller |
| MP4  | is one of the most common video formats. It offers good compression and supports multiple audio and video codecs, subtitles, and metadata |
| MOV  | the QuickTime multimedia file format developed by Apple, is primarily associated with QuickTime Player | 
| WAV  | an audio container format that commonly stores uncompressed audio to keep the original quality (though it can also contain compressed audio), and WebM, a high-quality open-source video format | 

| text type | - | description |
| ---- | --- | --- |
| TTF  | TrueType Font | is a font format compatible with different operating systems |
| WOFF  | Web Open Font Format | is a modern font format, specifically designed for web development purposes. These files are smaller because they have better compression. They can also store metadata, including licensing information |
| WOFF2  | - | is the successor of WOFF with even more efficient compression and performance |
 
| archive type | description |
| --- | --- |
| .zip | - |
| .rar | - |

| documentation type | description |
| --- | --- |
| .md / .markdown  | with Markdown, you can create structured documents with headings, subheadings, links, images, lists, and more |

*In web applications, you will usually find a file called README that contains information about the application, like how to use it, how to install it, its license, and how to contribute.*
